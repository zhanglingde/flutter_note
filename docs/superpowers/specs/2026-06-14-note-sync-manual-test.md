# 笔记同步功能 - 手动测试清单

每次发布前过一遍。

## 准备
- [ ] 准备两台设备（Windows + Android，或 Windows + Web）
- [ ] 坚果云账号已开通 WebDAV，获取应用密码
- [ ] 两台设备都配置好同步设置（URL、账号、密码、根目录 /notes-app/）

## 基础流程
- [ ] **新建笔记**：A 设备新建笔记 → B 设备启动后能拉到
- [ ] **编辑笔记**：B 设备编辑 → A 设备启动后能拉到更新
- [ ] **删除笔记**：A 设备删除笔记 → B 设备同步后该笔记也消失（墓碑机制）
- [ ] **离线编辑**：A 设备断网编辑 → 联网后自动同步

## 冲突场景
- [ ] **同时编辑**：A、B 都编辑同一笔记 → 同步后生成冲突副本（`__conflict-` 文件）
- [ ] **冲突查看**：底部面板点击"查看冲突副本" → 列表显示所有冲突
- [ ] **冲突删除**：删除一个冲突副本 → 列表刷新

## 资源同步
- [ ] **图片同步**：A 设备笔记插入图片 → B 设备能正确显示
- [ ] **视频同步**：A 设备笔记插入视频 → B 设备能正确播放
- [ ] **资源去重**：同一图片插入到不同笔记 → 远端 `/assets/` 只有一份

## 状态徽章
- [ ] **idle**：同步完成后显示"已同步 · N分钟前"
- [ ] **syncing**：同步中显示旋转图标
- [ ] **dirty**：本地有未推送笔记时显示橙色
- [ ] **offline**：断网时显示"离线"
- [ ] **error**：错误时显示红色，tooltip 有错误信息

## 错误处理
- [ ] **凭据错误**：填错密码 → 同步失败，徽章变红，错误信息提示
- [ ] **空间不足**：上传大文件超过坚果云限额 → UI 提示空间不足

## 设置页
- [ ] 保存配置 → 重启应用后配置仍在
- [ ] 测试连接按钮 → 显示成功/失败结果
- [ ] 立即同步按钮 → 立即触发同步
- [ ] 清理未引用资源 → 完成无异常
- [ ] 启用/禁用开关切换 → 重启后状态保持
