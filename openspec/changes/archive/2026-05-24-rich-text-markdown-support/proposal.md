## Why

用户在富文本编辑器中输入内容时，习惯使用 Markdown 语法（如 `**粗体**`、`# 标题`），但当前富文本编辑器不会自动识别和转换这些语法。这导致用户需要手动点击工具栏按钮来格式化文本，降低了输入效率。添加 Markdown 自动转换功能可以让用户在富文本编辑器中也能享受 Markdown 的便捷输入体验。

## What Changes

- **新增 Markdown 自动转换功能**：在富文本编辑器中，当用户输入 Markdown 语法并按下空格或回车键时，自动将其转换为对应的富文本格式
- **支持的 Markdown 语法**：
  - 标题：`# `、`## `、`### ` → H1、H2、H3
  - 粗体：`**文本**` 或 `__文本__` → **粗体**
  - 斜体：`*文本*` 或 `_文本_` → *斜体*
  - 删除线：`~~文本~~` → ~~删除线~~
  - 代码：`` `代码` `` → `代码`
  - 列表：`- ` 或 `* ` → 无序列表，`1. ` → 有序列表
  - 引用：`> ` → 引用块
- **新增转换开关**：在编辑器工具栏添加开关，允许用户启用/禁用 Markdown 自动转换
- **保持现有行为**：当转换功能禁用时，编辑器行为不变

## Capabilities

### New Capabilities

- `markdown-auto-convert`: 富文本编辑器中的 Markdown 语法自动检测和转换能力

### Modified Capabilities

- `rich-text-editing`: 新增 Markdown 自动转换作为富文本编辑的可选功能

## Impact

### 代码影响
- `lib/widgets/rich_text_editor.dart` - 需要添加文本输入监听和转换逻辑
- 需要实现 Markdown 语法检测器（基于正则表达式）
- 需要实现转换器将 Markdown 片段转换为 Quill Delta 操作

### 用户体验影响
- 提高熟悉 Markdown 用户的输入效率
- 不熟悉 Markdown 的用户不受影响（默认禁用或可关闭）
- 需要清晰的视觉反馈表明转换已发生

### 技术挑战
- Quill Delta 的精确操作（需要准确定位和替换文本）
- 撤销/重做行为需要正确处理
- 复合输入法（中文等）的兼容性
