## Why

用户在浏览知乎、小红书、抖音、B站等平台时，经常想将有价值的文章内容保存到笔记中。目前只能手动复制粘贴，效率低且格式丢失严重。需要一个网页剪藏功能，让用户输入链接后自动提取正文内容，以富文本格式插入到当前笔记中。

## What Changes

- 在编辑器工具栏左侧区域（现有图片按钮之后）新增一个 `LucideIcons.link2` 图标按钮
- 点击后弹出对话框，用户可输入网页链接
- 点击确定后，应用通过后端 API 抓取目标网页并提取正文内容
- 提取的正文以富文本格式（标题、段落、列表等）插入到当前光标位置
- 支持的主要平台：知乎、小红书、抖音、B站、微信公众号、通用网页

## Capabilities

### New Capabilities
- `web-clipper`: 网页链接剪藏能力——包含 UI 入口（工具栏图标 + 链接输入弹窗）、网页内容抓取与正文提取、富文本格式转换与插入

### Modified Capabilities

（无现有规格需要修改）

## Impact

- **UI 变更**: `rich_text_editor.dart` 的 `_buildToolbar()` 方法需要添加新图标按钮
- **新增文件**: 网页内容抓取服务类、链接输入弹窗组件
- **新增依赖**: HTTP 客户端（`http` 或 `dio`）、HTML 解析器（`html`）
- **数据流**: 抓取结果需要转换为 Quill Delta 格式并插入到编辑器
- **平台兼容**: Windows/Web/Android 三个平台的 HTTP 请求能力需验证
